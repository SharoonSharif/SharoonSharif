### Sharoon Sharif

Hardware–software co-design for efficient machine learning on constrained devices, from the instruction set up to deployed AI systems.

AI Integration Specialist at Faith Comes By Hearing · MS Electrical Engineering, Alabama A&M University · Albuquerque, NM

[Website](https://sharoonsharif.github.io) · [Google Scholar](https://scholar.google.com/citations?user=kL7K6LwAAAAJ&hl=en) · [LinkedIn](https://www.linkedin.com/in/sharoonsharif) · [ORCID](https://orcid.org/0009-0003-2669-1209)

#### Research

- **Computer architecture and FPGA acceleration.** Softcore processors for the MIPS and SOMA/SORA instruction sets, from single-cycle to pipelined; streaming vision accelerators on Zynq-7000; analytical DDR bandwidth-feasibility models.
- **Multimodal ML for computational pathology.** Survival prediction from whole-slide images and transcriptomics that holds up when a modality is missing, with audits of how existing fusion models actually use each input (five TCGA cohorts).
- **Low-resource speech.** TTS and ASR pipelines for low-resource languages.
- **Multi-agent robotics.** Decentralized multi-drone coordination.
